12-Month Roadmap

Month 0 — Week 1: Baseline Lock

Before anything is built or hired, document what exists: total users, active PRIME subscribers, active creators, monthly NowPayments volume. Define roles in writing. Set up Zoho One workspace. Open business bank account.

Exit criteria: Written baseline document. Roles defined. Zoho workspace live.

Month 1: Business Infrastructure

Zoho Books setup: chart of accounts, recurring expenses, n8n → Zoho Books payment sync, first P&L.
Zoho CRM setup: contact import (PRIME subscribers + creators), custom fields, n8n daily sync.
Zoho Recruit setup: creator application pipeline (9 stages), welfare interview template, red flag fields.
Hire: Operations Manager (target end of Month 1 — $1,200–2,000/month)
BullMQ: install, first queue (notification dispatch).

Exit criteria: First P&L. All payments tracked. Operations Manager hired. BullMQ handling notifications.

Month 2: Creator Operations

Creator welfare audit: review all active creators — welfare status, 2257 expiry, earnings trend, last contact.
Creator ATS live: all new applications through Zoho Recruit.
Hire: Creator Success Manager ($1,000–1,800/month)
Slack ops channels: #ops-payments, #ops-incidents, #ops-creator, #support-triage, #support-human.
BullMQ expanded: all payment-related jobs migrated.

Exit criteria: Creator ATS live. Creator Success Manager hired. Slack ops channels active. All payments through BullMQ.

Month 3: Automation Foundation

Hire: Welfare & Safety Officer ($1,200–2,000/month — start search Month 2)
n8n setup: new user → CRM, payment → Books, creator approved → welcome email, 2257 expiry chain, churn → re-engagement.
Circuit breakers: Opossum wrapping NowPayments, Telegram, Slack, Grok, SMTP, LiveKit.
Harm reduction partnerships: 2-3 LGBTQ+ organizations identified.

Exit criteria: n8n 5+ workflows live. Circuit breakers on all external services. Harm reduction partnerships identified.

Month 4: Creator Communications

Creator Slack onboarding: 80% of active creators in Slack by end of month.
Training canvases: Getting Started, Going Live, Private Calls, PNP Channels, Ru$h Tips, Rules & Compliance.
Creator notifications pipeline: all creator alerts → Slack #ext-[handle] ONLY (in-app disabled).
Hire: Content / Community Manager ($800–1,500/month)
First Zoho Campaigns drip sequences: PRIME welcome (3 emails / 7 days), creator onboarding sequence.

Exit criteria: 80% Slack adoption. All 6 canvases live. Content Manager hired. First sequences running.

Month 5: Marketing Engine

Hire: Growth Marketer ($1,200–2,000/month)
Zoho Campaigns replaces all broadcast scripts.
Referral programs live: creator referral (500 Ru$h bonus / 90 days), member referral (1 free month).
Re-engagement campaign: churned subscribers 30-90 days ago, A/B test subject lines.
OpenTelemetry + Grafana Tempo: slow queries, external latency, Socket.IO timing — all visible.
Creator Advisory Panel: 5 creators, rotating quarterly, $100/month cash or Ru$h equivalent.

Exit criteria: All scripts replaced. Referral programs live. First campaign sent and measured. OpenTelemetry live. Advisory Panel first meeting held.

Month 6: Platform Reliability + DevOps

Hire: DevOps / SRE ($1,500–2,500/month)
Notification Service extracted: standalone container, receives jobs from BullMQ, can restart independently.
Socket.IO Redis adapter: 2-line config change, enables horizontal scaling.
Stream recording → VOD pipeline: LiveKit Cloud recording, auto-save, n8n job → notify creator in Slack.
Mux Data analytics: viewer count, quality score, rebuffering rate per stream → Grafana.
First quarterly financial review.

Exit criteria: Notification Service live. Stream recording working. DevOps/SRE hired. Q1-Q2 P&L reviewed.

Month 7: Feature Excellence

Hire: CX Lead ($800–1,400/month)
Main Stage upgrades: tipping animations, viewer polls, pre-stream lobby, stream health display.
Private call improvements: Krisp AI noise cancellation, post-call rating, extension booking, call quality logging.
Hangout → Slack bridge: bidirectional messages, stickers as image attachments.
Creator analytics dashboard: earnings over time, viewer counts, call history, top tippers, subscriber growth.

Exit criteria: CX Lead hired. Tipping animations live. Noise cancellation on calls. Hangout→Slack bridge live. Analytics dashboard shipped.

Month 8: Growth & Expansion

Ticketed shows launch: creator creation flow, member purchase flow, Zoho Campaigns announcement.
Creator Training Certification: non-creator subscription to Creator Academy content.
Creator profile boosts: 1,000 Ru$h = 24hr boost in search/nearby/featured.
First paid marketing test: Telegram Ads, queer media partnerships ($500 test budget).
Zoho Sign rollout: updated creator agreement signed by all active creators.

Exit criteria: Ticketed shows live. Profile boosts live. First paid channel tested. All creators signed updated agreement.

Month 9: Consolidation

Media Processing Service extracted: ffmpeg, GIF generation, thumbnails → separate container, CPU-isolated.
2257 compliance audit: full audit of all active creators, automated suspension workflow for expired IDs.
Creator welfare review: Welfare Officer conducts 6-month check-in with every active creator.
Financial prep: all transactions reconciled, quarterly DIAN declarations current.

Exit criteria: Media Service extracted. 2257 audit complete. 9-month P&L reviewed. Tax obligations current.

Months 10–12: Scale Readiness + Phase 3 Planning

Team complete: all 10 positions filled.
Annual load test: simulate 10× current traffic, address bottlenecks.
First annual P&L + tax filing.
Creator cohort analysis: which cohorts have best retention and earnings.
Phase 3 Planning: B2B licensing evaluation, infrastructure migration assessment, investor readiness.

Hiring Gate Rule

Hiring is gated on revenue, not calendar. Operations Manager is hired regardless — they enable all financial visibility. Each subsequent hire: confirm MRR can absorb the cost with 3 months of runway margin. If revenue target is not on track by Month 3: delay Months 4-7 hires by 60 days and reassess.
